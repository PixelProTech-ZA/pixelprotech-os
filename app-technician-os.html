No Power / Won't Start
1
Check the power cable and outlet
ALWAYS FIRST
Try a known-working power cable. Test the wall outlet with another device. For laptops, test without battery (AC only). Try a different charger if available.
✓ If this solves it → faulty cable or outlet. Log and close ticket.
✗ No change → proceed to Step 2.
2
Check for surge damage indicators
🇿🇦 SA CHECK
Ask client: "Was there loadshedding before this?" Look for burnt smell, visible damage on PSU or board, discoloured capacitors. Check PSU fan — does it spin at all when power is applied?
✓ Surge indicators found → Go to ⚡ Surge Damage module
✗ No surge indicators → proceed to Step 3.
3
PSU test
TOOLS NEEDED
Use PSU tester or paperclip test (desktop only). Bridge PS_ON (green) to any ground (black) on the 24-pin connector. Fan should spin. Test 12V, 5V, 3.3V rails with multimeter.
✓ PSU dead → Replace PSU (R350–R800 SA). Test with known-good unit first.
✗ PSU OK → proceed to Step 4.
4
CMOS reset & minimal boot test
ISOLATE
Remove all non-essential components (GPU, extra RAM, HDDs, USB devices). Leave only 1 RAM stick in Slot 1. Clear CMOS (remove battery 30 sec or use CLRTC jumper). Attempt POST.
✓ Boots minimal → Add components back one by one to find culprit.
✗ Still no POST → suspect motherboard.
5
Motherboard / CPU fault determination
ADVANCED
Check for POST beep codes (use speaker). Inspect board visually — blown caps, burnt traces, bent CPU pins. Test with alternate CPU if available. Check RAM slots for damage. Use POST debug card if available.
Dead motherboard: R800–R3,500 SA replacement. Always quote parts + labour separately. Consider board-level repair if CPU socket is the fault.
No Display / Black Screen
1
Confirm device is actually posting (listen for beeps, HDD activity)
Listen for POST beeps, HDD spin, fan speed changes. If you can hear Windows login sound — device is running, only display is fault. Check power LED vs HDD LED activity.
Device running = display/cable/GPU problem. Device silent = POST failure — go to No Power wizard.
2
Test with external monitor
Connect via HDMI/VGA/DisplayPort to external monitor. For laptops — check if Fn+F4/F8 (display switch) activates external output. Test at BIOS level, not just Windows.
✓ External works → laptop screen, backlight inverter, or LVDS cable fault.
✗ No external either → GPU or motherboard display output fault.
3
RAM reseating
Remove all RAM. Clean slots with compressed air. Reseat with single stick in primary slot. If 2 sticks — test each individually. Swap slots. Memory is the #1 cause of no-display that isn't GPU.
✓ Boots with one stick = bad RAM stick or slot. Test each to find faulty unit.
4
GPU test (discrete)
Remove discrete GPU. Test via onboard/integrated graphics. If no integrated output, test with known-good GPU. Check PCIe power connectors are fully seated. Check GPU for burnt components (surge check).
✓ Works without GPU = faulty GPU (R400–R4,000+ replacement)
✗ Same with integrated = motherboard video output fault
Boot Failure / Bootloop / BSOD
1
Read the error message exactly
Note the exact BSOD stop code (e.g. CRITICAL_PROCESS_DIED, INACCESSIBLE_BOOT_DEVICE). Go to Error Codes module to look it up. Take photo with phone if needed.
INACCESSIBLE_BOOT_DEVICE = usually dead/failing HDD or SSD
CRITICAL_PROCESS_DIED = usually Windows corruption or driver issue
2
Run SMART test on drive
Boot from USB (CrystalDiskInfo or HDDScan). Check SMART attributes — Reallocated Sectors, Pending Sectors, Uncorrectable Errors above 0 = drive is dying. SSD: check for wear level.
SMART fail → backup data immediately, replace drive. Quoted SA: R350–R600 SSD replacement.
3
Windows repair from recovery environment
Boot Windows USB → Troubleshoot → Advanced → Startup Repair. If fails, try: bootrec /fixmbr then bootrec /fixboot then bootrec /rebuildbcd. Also run sfc /scannow offline and DISM restore.
If SFC/DISM clears = corruption fixed. If unrecoverable = reinstall Windows. Always backup first.
Overheating / Thermal Shutdown
1
Confirm temps — install HWMonitor or HWiNFO
Normal idle temps: CPU 35–55°C, GPU 40–65°C. Normal load: CPU up to 85°C, GPU up to 90°C. Throttling/shutdown usually kicks in at 95–105°C CPU, 95°C+ GPU.
If temps spike to 95°C+ within 2 minutes = thermal compound or airflow failure.
2
Clean dust from heatsink, fans, and vents
Use compressed air. For laptops — remove bottom panel, clean fan and heatsink fins thoroughly. Dust buildup is the #1 cause of overheating in SA (especially Highveld dust). Clean all intake and exhaust paths.
Before: 98°C | After clean: often drops to 65–75°C. Always clean before repasting.
3
Replace thermal paste
Old thermal paste dries and cracks after 3–5 years. Remove heatsink, clean old paste with IPA. Apply new paste (Arctic MX-4, Noctua NT-H1). Use correct amount: pea-size for Intel, X-pattern for AMD. Reseat and tighten in X-pattern.
SA cost: R80–R150 for quality thermal paste. Include in service quote. Drop of 15–25°C typical after repaste.
Data Recovery Workflow
⚠ Manage Expectations First
Before starting recovery, be honest with the client: data recovery is not guaranteed. Set expectations clearly via WhatsApp before you begin. If data is critical, refer to a professional data recovery lab (Stellenbosch/JHB options available).
1
Triage: logical vs physical failure
Connect drive externally via USB SATA adapter. Does it spin up? Does it click? Clicking = physical platter damage (DO NOT continue — lab only). Spins up + recognized = logical failure. Not recognized at all = PCB or firmware failure.
Logical failure → you can attempt recovery. Physical failure → stop, refer to lab.
2
Create sector-by-sector image first
NEVER work on original failing drive. Use ddrescue (Linux) or HDDRawCopy to clone to healthy drive first. Then work from clone. This preserves evidence and prevents further damage to original.
ddrescue -d -r3 /dev/sdX /dev/sdY recovery.log
3
Run Recuva / TestDisk / PhotoRec
TestDisk: repairs partition table, recovers deleted partitions. PhotoRec: recovers files by file signature regardless of filesystem. Recuva (Windows): user-friendly, deep scan mode. For NTFS: also try MFT repair via Windows Recovery.
Quote R450–R1,500 for data recovery service depending on drive size and complexity. Always get approval before starting.

Boot into Windows Recovery Environment → Troubleshoot → Advanced Options → Startup Repair. Let it run. If it fails after 3 attempts, proceed to manual repair below.

C:\> bootrec /fixmbr
→ Writes a new MBR to the system partition
C:\> bootrec /fixboot
→ Writes a new boot sector
C:\> bootrec /rebuildbcd
→ Scans for Windows installs and rebuilds BCD
→ Restart after each step

F8 on boot → Advanced Boot Options
SFC — System File Checker
# Run as Administrator
C:\> sfc /scannow
→ Scans and repairs protected system files
→ Takes 10–30 min. Do not interrupt.
 
# If Windows won't boot — offline SFC:
C:\> sfc /scannow /offbootdir=C:\ /offwindir=C:\Windows
 
# Check SFC log:
findstr /c:"[SR]" %windir%\Logs\CBS\CBS.log
DISM — Restore Health
# Run these IN ORDER — Admin CMD
 
C:\> DISM /Online /Cleanup-Image /CheckHealth
→ Checks for corruption flags
 
C:\> DISM /Online /Cleanup-Image /ScanHealth
→ Full scan (takes 5–10 min)
 
C:\> DISM /Online /Cleanup-Image /RestoreHealth
→ Downloads and repairs corruption
→ Run SFC again after DISM completes
