    How Pixel works

    • Live preview runs inside a sandboxed frame. Scripts and forms are allowed so real demos work, but the frame cannot access this page, your storage, or read other tabs.
    • Note → HTML uses fixed local rules, not an AI model. The same note always produces the same result.
    • Nothing leaves your device. Your code and progress are stored only in this browser, using local storage.
    • External AI code welcome. Paste code from GPT, Claude, or anywhere else straight into the editor and run it.
